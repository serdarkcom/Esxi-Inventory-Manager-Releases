# ESXi Inventory Manager

ESXi, VMware ve vCenter ortamları için envanter, sağlık kontrolü, snapshot yönetimi ve raporlama uygulaması.

## Özellikler

- ESXi ve vCenter bağlantısı
- Host sağlık durumu
- Sanal makine envanteri
- VM donanım ve IP bilgileri
- Snapshot görüntüleme ve yönetimi
- Datastore kapasite kontrolü
- HTML ve Excel raporlama
- Alarm ve bildirim desteği

## İndirme

Programın en güncel sürümünü Releases bölümünden indirebilirsiniz.

## Sistem Gereksinimleri

- Windows 10 veya Windows 11
- Windows Server 2016 ve üzeri
- ESXi veya vCenter erişimi

## Güvenlik

Uygulama içinde girilen erişim bilgileri kullanıcı bilgisayarında tutulur. GitHub üzerinde herhangi bir kullanıcı adı veya parola saklanmaz.
