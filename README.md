# ESXi Inventory Manager

[English](README.md) | [Türkçe](README_TR.md)

ESXi Inventory Manager is a Windows desktop application designed to discover, inventory, monitor and report VMware ESXi and vCenter environments.

## Features

- ESXi and vCenter connectivity
- Host health overview
- Virtual machine inventory
- VM hardware information
- Guest operating system and IP address information
- Datastore capacity monitoring
- Snapshot discovery and management
- Inventory and health reporting
- HTML and Excel report support
- Alert and notification infrastructure

## System Requirements

- Windows 10 or Windows 11
- Windows Server 2016 or later
- VMware ESXi or VMware vCenter access
- Network connectivity to the target environment

## Installation

1. Open the Releases section.
2. Download the latest ZIP package.
3. Extract the ZIP file to a folder.
4. Run `EsxiInventoryManager.exe`.
5. Enter the ESXi or vCenter connection information.

## Security

Credentials entered in the application are not published on GitHub.

Do not upload passwords, API keys, vCenter credentials, configuration files or log files containing sensitive information to GitHub.

## Reporting Issues

You can report bugs and request new features using the GitHub Issues section.

When reporting a problem, include:

- Application version
- Windows version
- ESXi or vCenter version
- Error message
- Relevant log details with sensitive information removed
